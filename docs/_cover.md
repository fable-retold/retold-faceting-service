# Retold Faceting Service

> Facets for any retold-data-service, computed through each entity's own list behaviors so the counts always agree with the list

- Terms, date and numeric histograms, ranges, stats, distinct counts, missing counts and 2-D pivots
- Disjunctive faceting: a selected value never drives its siblings to zero
- Cross-entity folds and named scopes, declared in JSON definitions files
- Optional result cache, change feed and ClickHouse store, with per-facet freshness
